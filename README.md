# نشر محتوى وِرد بحسابك

الحزمة جاهزة في `C:\dev\my_app\content_site`. لا تتضمن التسجيلات الشخصية أو أصوات الأذان أو APK أو بيانات المستخدم. لم يُنشأ مستودع ولم يُنشر موقع من حسابك أثناء التطوير.

1. ثبّت Git وGitHub CLI إن لم يكونا متاحين، ثم سجّل الدخول بنفسك بواسطة `gh auth login`.
2. راجع الحزمة أولاً، مع استبدال `YOUR_ACCOUNT` بمعرّفك الحقيقي واختيار اسم مستودع جديد:

   ```powershell
   .\tool\publish_content.ps1 -Repository YOUR_ACCOUNT/wird-content
   ```

3. للنشر الفعلي، نفّذ:

   ```powershell
   .\tool\publish_content.ps1 -Repository YOUR_ACCOUNT/wird-content -Publish
   ```

   ينشئ السكربت مستودعاً عاماً جديداً فقط، ويرفض الكتابة فوق مستودع موجود. يستخدم تسجيل دخول GitHub CLI، ولا يحتاج التطبيق إلى مفتاح أو رمز وصول. لا ترسل أي كلمات مرور أو رموز في المحادثة.
4. انتظر نجاح workflow باسم **Publish Wird content**. إن لم يسمح الحساب بتمكين Pages آلياً، افتح Settings → Pages → Source: GitHub Actions، ثم شغّل workflow من Actions.
5. سيطبع السكربت رابط مجلد المكتبة. ألصقه في وِرد → الإعدادات → رابط مكتبة المحتوى. افتح المكتبة وحدّث الفهرس، أو افتح صفحة من المصحف لتنزيلها. لا يلزم بناء APK جديد لتغيير رابطك.

قبل النشر، لن يختلق التطبيق رابطاً ولا صفحات بديلة. الصفحات والكتب غير المنزّلة تحتاج الرابط المنشور والإنترنت أول مرة؛ الملفات التي اكتمل تنزيلها تُفحص ببصمتها وتبقى على الجهاز بعد إغلاق التطبيق. حفظ العلامة وآخر صفحة لا يعتمد على الإنترنت. يمكن تنزيل المصحف كاملاً أو قراءة مقاطع الكتب عند الحاجة.

## مصادر المحتوى والحقوق

- صفحات المصحف: الصور الأصلية نفسها، 604 صفحة، وبصمات مطابقة للنسخة السابقة. تراخيص مجمع الملك فهد والمصدر والتجهيز موثقة في ASSET_CREDITS.md وquran-source-manifest.json.
- الإنجليزية: Rowwad وNoor International من QuranEnc؛ الأردية: محمد إبراهيم جوناگڑھی. يحفظ كل ملف بيانات الناشر ورقم النسخة والحواشي والنص دون إعادة صياغة. يجب النسبة إلى QuranEnc، إبقاء بيانات النسخة، متابعة تحديثات المصدر وإبلاغه بالملاحظات، وعدم وضع إعلانات غير ملائمة. الشروط: https://quranenc.com/en/home/api .
- أحد عشر تفسيراً عربية ونسختان عربيتان من صحيحَي البخاري ومسلم: OpenITI، الإصدار المثبّت v2025.1.9. ترخيص CC BY-NC-SA 4.0: استخدام غير تجاري مع النسبة والمشاركة بالمثل للملفات المشتقة، دون ادّعاء اعتماد OpenITI للتطبيق. مصدر كل ملف ومعرّف طبعته ورأسه وبصمته محفوظة في الفهرس والأجزاء. بيان الترخيص: https://github.com/OpenITI/documentation/blob/master/index.md . بيانات المصدر قد تحتوي أخطاء نسخ؛ ليست مراجعة علمية جديدة من مطوّر وِرد.
- المقاطع ذات PageV هي صفحات الطبعة الأصلية، وبعض النسخ لا تتضمن ترقيم صفحات فقُسمت عند أسطر النص إلى مقاطع رقمية. لا تمثل هذه الأرقام صفحات المصحف ولا ربطاً مخمّناً بآياته.
- لم تُنسخ ترجمات إنجليزية/أردية للتفاسير أو الصحيحين لم تتضح حقوقها. ترخيص MIT لمستودع برمجي لا يثبت حقوق كل كتاب يحتويه. وثائق Tafsir Center المنشورة تجمع CC BY 4.0 مع اشتراط إذن لإعادة النشر التجاري؛ لم تُستخدم قاعدة البيانات ذات الشروط المتعارضة. نتائج البحث والمصادر المستبعدة موثقة في CONTENT_SOURCES.md.

## التحديث والحدود

`tool/prepare_content.py --refresh` يحدّث بيانات الترجمات من المصدر ثم يعيد بناء الملفات والفهرس. راجع تغيّر النسخ والحقوق قبل إعادة النشر. لا يُرفع تحديث آلي إلى حسابك. حافظ على SOURCE_NOTICES.md وASSET_CREDITS.md والفهرس عند النشر. لا تغيّر النصوص الدينية لتحسين الصياغة.

الحزمة نحو 251 MB، دون ملفات ضخمة منفردة. GitHub Pages له حدود سعة ونقل وتوفّر؛ راجع https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits . التخزين المحلي يقلّل الطلبات؛ لا توجد خدمة مدفوعة أو اعتماد على API يومي لعرض المحتوى المنزّل. إعداد رابط الاستضافة خطوة لازمة ينفذها صاحب الحساب بعد النشر.
